# junjeon.com

Personal site for Jun Jeon, served by GitHub Pages from the root of `main`.

The whole site is `index.html` and `styles.css`. Edit either one and push to `main`; Pages republishes in about a minute. To preview locally, run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

`404.html` sends unknown paths (including old Notion page URLs) back to the home page.

The June 2026 JWJ LLC React draft is kept on the local `jwj-llc-draft` branch.
